# Política de Segurança — hubsaude-cliente-cli

## Versões suportadas

Apenas a versão MAJOR mais recente recebe correções de segurança.

## Como reportar uma vulnerabilidade

Não abra uma issue pública. Use um private security advisory em:

<https://github.com/sesgo-ti/hubsaude-cliente-cli/security/advisories/new>

Inclua, sempre que possível, descrição do impacto, passos mínimos para
reprodução, versões afetadas e mitigação sugerida.

## Escopo

Esta política cobre o código-fonte e os artefatos publicados pelo repositório
`sesgo-ti/hubsaude-cliente-cli`.
